# NetBaseline

פרויקט גמר במגמת סייבר, כיתה י"ב, חלופת "הגנת סייבר ומערכות הפעלה".

מערכת לניתוח תעבורת רשת וזיהוי התנהגות חריגה. כל מחשב נמדד מול השגרה של עצמו, ולא מול חוקים קבועים.

## מבנה הריפו
- `docs/` — מסמכי הפרויקט: הצעת הפרויקט, רשימת ההתנהגויות להדגמה, ומסמך האפיון (בכתיבה).

## סטטוס
שלב תכנון ואפיון. עדיין אין קוד.
